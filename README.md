# Aperture Science Company Page
Welcome to the GrowSquid's second ever Hackclub Project!  
I have created a website in HTML based on Aperture Science's past.  
Aperture Science, and all related assets from Portal belong to Valve.  

## Features  
Layouts of Aperture's Products
Rosters of Aperture's Employees  
Pictures with custom backgrounds for all of the above
